# dev-portfolio

A modern, responsive personal portfolio built with React, TypeScript, and Tailwind CSS.

---

## ✨ Features

- **Hero** — Intro with name, role, and social links (GitHub, LinkedIn, Email)
- **About** — Bio with Clean Code, Design Focus, and Performance highlights
- **Skills** — Visual progress bars for React, TypeScript, Node.js, Tailwind CSS, PostgreSQL, AWS
- **Projects** — Featured project cards with tags and external links
- **Contact** — Contact form with name, email, and message fields

---

## 🛠 Tech Stack

| Layer      | Technology                        |
|------------|-----------------------------------|
| Framework  | React 18 + TypeScript             |
| Styling    | Tailwind CSS                      |
| Icons      | Lucide React                      |
| Backend    | Supabase (via `@supabase/supabase-js`) |
| Build Tool | Vite                              |

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
